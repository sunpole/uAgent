# Установка и запуск uAgent

> **Статус:** приложение пока не реализовано. Этот файл не предлагает фиктивных команд запуска.

## Целевая среда

- Windows 10/11, 64-бит.
- Локальная модель, которую можно запустить без отдельного API-ключа.
- Изолированное окружение Python либо другого выбранного рантайма.
- Git для контроля версий.
- В дальнейшем — защищённый локальный веб-сервер и доступ через доверенную сеть.

## Что будет описано после первого успешного запуска

1. Точная версия выбранной модели и проверенная ссылка на её лицензию.
2. Проверенная последовательность установки с контрольными командами.
3. Требования к ОЗУ, диску и, при наличии, видеокарте.
4. Проверенные команды запуска, остановки и обновления.
5. Результаты замеров скорости и качества на целевой машине.
6. Откат, удаление и защита файлов/ключей.

## Безопасность

- Не публиковать API-ключи, токены и пароли.
- Не открывать управляющий веб-интерфейс напрямую в Интернет.
- Не разрешать агенту выполнять произвольные команды или изменять другие проекты без подтверждения.
- При работе с GitHub использовать отдельные ветки и Pull Request.
- Не путать локальную модель и обычный ChatGPT Plus: память и подписка автоматически не переносятся.
