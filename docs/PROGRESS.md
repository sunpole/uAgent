## Что дальше

1. Выбрать локальную модель с учётом фактической конфигурации ПК.
2. Запустить её в отдельной тестовой среде, записать скорость, память и ограничения.
3. Реализовать минимального агента с разрешениями и проверками.
4. Добавить память, GitHub и мобильный интерфейс.
5. Публиковать подтверждённые результаты в uNews по установленной политике.

Любое утверждение об успешной работе должно иметь воспроизводимую инструкцию или проверку.

## 2026-11-16 — Подтверждён первый запуск локальной модели

- По выводу PowerShell: Ollama `0.40.16` установлена, `qwen2.5-coder:3b` скачана и запущена, проверка SHA-256 прошла.
- Первый тест: 200 токенов, **8,04 токена/с**, неподходящий ответ по-китайски при первоначальной настройке.
- Исправленный запрос через локальный `/api/chat` с русской системной инструкцией и UTF-8: корректный пример Python-функции `is_prime`, три демонстрационных примера, **8,03 токена/с**.
- Завершение `done_reason: length` при установленном ограничении 240 токенов — конец объяснения обрезан; полный ответ не проверялся.
- `ollama ps`: Qwen2.5-Coder 3B, **2,5 ГБ**, **75% CPU / 25% GPU**, контекст **4096**, `llamacpp`.
- Проблема скачивания решена предпочтением IPv4 (временная prefix policy). Это не означает, что настройки сети нужно менять всем.
- Агент, доступ к файлам, память и мобильное управление пока не реализованы.
- До этого этапа **ни одного поста uAgent в uNews опубликовано не было**. Следующий приоритет — подлинное изображение и вступительный `intro`, по [UNEWS_POLICY.md](UNEWS_POLICY.md).
