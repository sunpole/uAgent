Что мы создаём

Практичный проект для реального домашнего компьютера, а не демонстрацию возможностей без результата.

01 / МОДЕЛЬ

Локальный ИИ

Подбор и проверка небольших моделей на доступном оборудовании. Измеряем скорость и качество, не обещаем уровень облачных флагманов.

02 / ИНСТРУМЕНТЫ

Агент разработки

Память проектов, контролируемая работа с кодом, тесты и GitHub. Опасные действия — только после подтверждения.

03 / ДОСТУП

Лёгкий веб-пульт

Простой интерфейс для старого телефона. Тяжёлые вычисления остаются на домашнем ПК; удалённый доступ защищён.

Дорожная карта

Отмечаем выполненное только после проверки. Все этапы доступны в репозитории.

  1. 01. Репозиторий создан16 ноября 2026 — GitHub, правила безопасности, исходная документация.
  2. 02. Первый запуск локальной моделиПодбор модели, проверка производительности и русского языка. В работе.
  3. 03. Безопасный агент с тестамиИзолированные задачи, проверка кода, контроль разрешений.
  4. 04. Память и GitHubДокументы решений, история задач и Pull Request.
  5. 05. Мобильное управлениеБыстрый веб-интерфейс и защищённое соединение.

Прогресс и запуск

Здесь публикуются подтверждённые результаты разработки. Инструкция по установке будет дополняться по мере появления работающего кода.

Текущий статус: подготовка инфраструктуры

Репозиторий создан. Рабочая локальная модель, агент и мобильный пульт пока не представлены. Первые измерения и команды запуска появятся после испытаний — без вымышленных результатов.
