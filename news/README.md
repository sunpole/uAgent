# uAgent → uNews / «тыНовости»

Публичные новости uAgent предназначены для Telegram-канала [@uNewsLog](https://t.me/uNewsLog).

**Текущее состояние:** каталог подключён к структуре проекта, но публикаций ещё нет. Никакие токены Telegram в этот репозиторий не добавляются.

Система [sunpole/uNews](https://github.com/sunpole/uNews) сканирует папки `news/` публичных репозиториев и публикует только прошедшие политику материалы.

## Условия первой публикации

1. Репозиторий uAgent должен быть публичным, сайт GitHub Pages — действительно доступным.
2. Самый первый датированный пост должен иметь `type: intro`, `project: uAgent`, `series: uagent`.
3. Обязательно приложить **реальный скриншот** работающей опубликованной страницы или другого реального результата. Нельзя подменять его AI-generated картинкой или макетом.
4. Указать `image_origin: real`, имя изображения, `queued_at` в UTC, `repo_url`, `web_url`.
5. Не писать вручную финальные Telegram-ссылки и хештеги в коротком тексте: политика uNews добавляет footer самостоятельно.
6. Проверить файл политикой uNews до постановки в очередь. Публикацию выполняет только GitHub Actions проекта uNews. Не публиковать непосредственно с локального компьютера.

## Пример метаданных будущего intro-поста (не готов к публикации)

```yaml
type: intro
project: uAgent
series: uagent
title: uAgent — открыт журнал разработки локального ИИ-агента
version: 0.1.0
queued_at: <UTC-дата-время-подготовленного-поста>
repo_url: https://github.com/sunpole/uAgent
web_url: https://sunpole.github.io/uAgent/
image: <имя-реального-скриншота>.png
image_origin: real
```

Имя файла для публикации: `YYYY-MM-DD-uagent-intro.md`. До подтверждения изображения не создавать датированный файл: uNews может поставить его в очередь.

После первого успешного intro uNews сохраняет ссылку «О проекте» для дальнейших постов этой серии. Подробнее: [документация uNews](https://github.com/sunpole/uNews#главный-пост-проекта-и-ссылка-о-проекте).
