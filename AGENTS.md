# AGENTS.md — uAgent

Основной язык: русский. Источник истины — текущая версия в version.json. История — patches/*.json.
**Режим:** начальная разработка. Локальный ИИ, граф символов и мобильное управление пока не объявлять работающими.

## Перед изменениями
1. Прочитать README.md, docs/RELEASE_POLICY.md и docs/PROGRESS.md.
2. Перед изменением кода изучить подходящие файлы; docs/REPO_MAP.md только навигация, не подмена исходникам.
3. Создать отдельную ветку и PR. Не менять другие репозитории, production/VPS, настройки сервера или Telegram без разрешения.
4. Новый набор изменений = новая версия SemVer + patches/<version>.json. Удобный способ: npm run patch:new -- --title "..." --summary "..." --tags "тег1,тег2".
5. Каждый патч должен фиксировать реальные изменения. verified=true только после реальной проверки; без выдуманных тестов.
6. После работы выполнить npm run build, npm run graph и npm run check; при отсутствии возможности запускать — указать это явно.
7. Не размещать пароли, API-ключи, токены, личные файлы, дампы БД, модельные веса в GitHub.
8. Для сетевых интерфейсов — loopback по умолчанию, удалённый доступ только через защищённое соединение с аутентификацией.
9. Архив патчей хранится в patches/. Датированный файл news/ — это **очередь Telegram**, не место черновиков.
10. uNews публикует только реальное изображение и проверенный intro-пост, без фальшивых скриншотов и ручного footer. Источник правил: sunpole/uNews.
11. Не сливать PR до успешных проверок. Не трогать чужие проекты и инфраструктуру.
