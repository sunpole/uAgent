# uAgent

Собственный локальный ИИ-агент для Windows.

## Основные цели

- Бесплатная локальная ИИ-модель.
- Долговременная память проектов.
- Работа с файлами и GitHub.
- Автоматическое тестирование кода.
- Лёгкий мобильный веб-интерфейс.
- Безопасное управление действиями агента.

Статус: начальная разработка.
