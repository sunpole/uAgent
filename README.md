**uAgent** — открытый журнал создания локального ИИ и безопасного агента разработки на домашнем Windows-ПК.

> **Важно:** это **начальная стадия**. Локальная модель **уже запущена и проверена** (Ollama 0.40.16, Qwen2.5-Coder 3B, 8,03 токена/с); **автономный агент**, память и мобильный пульт пока не реализованы. Страница проекта и документация описывают план и подтверждённый прогресс, а не выдают будущие возможности за работающие.

| uNews | Первый intro с реальным изображением; политика на каждый выпуск | Готовится |

### Как будем работать

1. Проверяем качество и скорость небольших локальных моделей.
2. Собираем минимального агента и тестируем только на безопасных задачах.
3. Добавляем контролируемую работу с кодом, памятью и GitHub.
4. Создаём лёгкий интерфейс для старого телефона.
5. Публикуем воспроизводимые инструкции и реальный прогресс.

Никаких утверждений о скорости или возможностях до фактической проверки.

### Новости uNews

Все сообщения для Telegram хранятся в [`news/`](news/README.md). Первым должен быть **intro-пост** с реальным скриншотом работающей страницы или результата. Система [sunpole/uNews](https://github.com/sunpole/uNews) проверяет и публикует новости через GitHub Actions; токены не хранятся здесь.

### Безопасность

Никаких API-ключей в репозитории, автоматического изменения других проектов или прямого доступа к управляющим интерфейсам из открытого Интернета. Разработку ведём через ветки и PR. [Правила для агентов](AGENTS.md).

### Быстро добавить патч

Сайт [uAgent](https://sunpole.github.io/uAgent/#updates) показывает все записи из `patches/*.json` (новые сверху). Не нужно вручную редактировать HTML:

```powershell
npm run patch:new -- --title "Новая функция" --type feature --tags "ИИ,код,тесты" --summary "Кратко о реальных изменениях"
npm run check
```

Команда поднимает SemVer PATCH, обновляет единственный `version.json`, генерирует `version.md` и сайт. Подробности: [единая политика релизов](docs/RELEASE_POLICY.md).

[Файловый граф зависимостей](docs/REPO_MAP.md) и [JSON-граф](docs/repo-graph.json) формируются через `npm run graph`. Это стартовая навигационная карта, **не** полноценный анализ функций или вызовов. Расширение Tree-sitter/SCIP: [проектирование](docs/CODE_GRAPH.md).
